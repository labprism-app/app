How to inspect a lab result’s fields in LabPrism

Find the value, unit, source reference text and status behind a lab entry, and inspect the normalized observation without inventing missing information.

By the LabPrism project · Published September 9, 2026 · Software guide

On this page

  1. Select the exact entry
  2. Read the value together with its context
  3. Expand the normalized observation
  4. Keep a route to the original report
  5. Questions about this guide

Select the exact entry

The result list shows a label and the date available to the app. Select the entry you want to inspect before comparing details. Similar labels do not establish that two observations used the same method or should be treated as interchangeable.

Read the value together with its context

The selected panel displays the result quantity, status, source reference text and any supplied interpretation. Read these together instead of copying the number alone. LabPrism does not generate a replacement reference range when the source omits one.

  1. Check the selected label and available code.
  2. Keep the unit beside any numerical value you discuss.
  3. Distinguish source interpretation from your own question about it.
  4. Notice any field explicitly marked as not supplied.

Expand the normalized observation

The inspector below the panel exposes the returned object. Use it to check which field supports the display and whether additional context was returned. The object is the normalized representation used by this app, not a promise of the original lab report or every field in the source system.

Keep a route to the original report

If a value or field needs clarification, consult the original report and the appropriate care professional. The app does not diagnose conditions, recalculate laboratory ranges, or establish a historical trend. Public explanations are available now; live imports still depend on production activation.

Questions about this guide

Why does a result have no reference range?

The returned entry may not contain one. LabPrism displays that absence instead of substituting a general range.

Is the JSON panel the original laboratory document?

No. It shows the normalized entry supplied to the app, which can differ from the original document.
